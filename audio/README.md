# Música de fondo

Coloca en esta carpeta el archivo de audio que quieras usar y nómbralo exactamente:

`cancion.mp3`

La página lo reproduce en bucle al pulsar **Abrir**, con volumen inicial al 35 %. El botón de altavoz permite silenciarlo y volver a activar el sonido.

Puedes usar un archivo MP3 propio o uno que tengas permiso para publicar. El navegador puede bloquear la reproducción si el archivo no existe o no se puede cargar.
